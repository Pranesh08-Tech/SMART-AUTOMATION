#SMART ENERGY SAVING IN ROOM USING CLAP SENSOR
 is a simple, low-cost automation project designed to control a room light using clap detection with a microphone module and Arduino Uno R3. The main objective of this project is to reduce unnecessary electricity consumption while providing a convenient alternative to traditional manual switches. The system consists of an Arduino Uno R3, microphone module, relay module, LED/bulb, breadboard, jumper wires, resistor, and power supply. The microphone module detects sound and sends the signal to the Arduino, which processes the sound pattern to identify a valid double-clap. When two claps are detected within a short time window of 0.3–0.8 seconds, the Arduino activates or deactivates the relay, thereby turning the light ON or OFF. A single clap, normal speech, or background noise is ignored to reduce unwanted triggering. The relay acts as an electronic switch between the Arduino control system and the light. This project demonstrates how basic embedded systems and sound-sensing technology can be combined to create a user-friendly energy-saving solution. It is easy to build, affordable, and suitable for demonstrating practical applications of Arduino-based automation. Overall, the project shows that a simple double-clap mechanism can provide convenient light control while supporting efficient energy usage.
